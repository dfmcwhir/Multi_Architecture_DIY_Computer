#<h2>AY-3-8910 sound card</h2>

<p>This a new card that hasn't been built or tested yet. However, a rev0 of the AY-3-8910 portion of this card was built and tested on a prototyping board and worked for sound. For this version of the card the I/O ports A and B were broken out and can be used for general purpose IO. The SPO3 speech chip was added to this version of the board as well.</p>
