<h2>ISA_TMS9918</h2>

<p>This is a new card that hasn't been built or tested yet. It is designed around the old TMS9918A chip and outputs composite video for a more retro feel. Or, most of the components can be left off and a PICO9918 can be used for VGA or HDMI output. Also, as a test, two TMS cards can be connected together to increase the graphics capabilities. This is allowed per the TMS9918 datasheet, but it may (likely?) will not work in this implementation. To link the two cards together it requires both cards to be clocked by the same clock. Probably the best way of doing that would be to use an oscillator and run that through a buffer and an inverter to the XTAL1 and XTAL2 inputs for both TMS9918 chips (the XTAL1 and XTAL2 inputs apparently need inverses of each other from my research), but I couldn't find a through hole oscillator of the correct frequency, so basically this card has a header that can connect the crystal pins to both chip's XTAL pins (which is actually what the datasheet shows), but I don't know if that will work or if the whole setup will be too noisy. It is an experiment. If it doesn't work then it should still work as a stand alone card and the dual card concept can be revisited later.</p>
